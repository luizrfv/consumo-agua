## 📌 Sobre o Projeto
Desenvolvido como parte de uma campanha de conscientização ambiental de uma companhia de saneamento. É um script que classifica o perfil de consumo de água dos imóveis e emite alertas educativos aos moradores, visando combater o desperdício.

## ⚙️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Controle de Versão:** Git & GitHub
